# MMO 3D

Браузерная 3D MMO. GitHub Pages публикует клиент, Colyseus обслуживает тестовую комнату `world`.

## Локальный запуск

Нужен Node.js 24.

```sh
npm ci
npm run server
```

Во втором терминале запустите `npm run dev`. Откройте адрес Vite в двух вкладках и введите ник длиной до 24 символов и нажмите «Начать игру». Обе вкладки покажут двух игроков. После закрытия одной вкладки счётчик уменьшится.

## Развёртывание

Клиент собирается командой `npm run build`. GitHub Actions публикует `dist/` и задаёт `VITE_COLYSEUS_URL`. Эта переменная содержит публичный HTTPS-адрес сервера, включая префикс при наличии.

Сервер собирается отдельно через `docker build -t mmo-3d .`. Контейнер слушает `2567`. В текущем развёртывании порт опубликован только на loopback, HAProxy завершает TLS и перенаправляет HTTP и WebSocket с префикса `/mmo/`, удаляя его перед отправкой в Colyseus.
