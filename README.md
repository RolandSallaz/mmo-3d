# MMO 3D

Браузерная 3D MMO. GitHub Pages публикует клиент, Colyseus обслуживает тестовую комнату `world`.

## Локальный запуск

Нужны Node.js 24 и база PostgreSQL. Создайте выделенную базу для игры и задайте `DATABASE_URL` в окружении сервера или в локальном файле `.env` в корне проекта. При первом запуске сервер создаст таблицу инвентаря.

```sh
npm ci
npm run server
```

Во втором терминале запустите `npm run dev`. Откройте адрес Vite в двух вкладках и введите ник длиной до 24 символов и нажмите «Начать игру». Обе вкладки покажут двух игроков. После закрытия одной вкладки счётчик уменьшится.

## Управление

ЛКМ задаёт курс, ПКМ стреляет из установленных лазеров. Их можно установить в два оружейных слота через инвентарь. Наведите курсор на корабль, чтобы увидеть прочность и щит.

Груз и экипировка сохраняются в PostgreSQL. Прототип узнаёт персонажа по токену, сохранённому в браузере.

## Развёртывание

Клиент собирается командой `npm run build`. GitHub Actions публикует `dist/` и задаёт `VITE_COLYSEUS_URL`. Эта переменная содержит публичный HTTPS-адрес сервера, включая префикс при наличии.

Сервер собирается отдельно через `docker build -t mmo-3d .`. Передайте контейнеру `DATABASE_URL` с подключением к постоянной базе PostgreSQL. Контейнер слушает `2567`. В текущем развёртывании порт опубликован только на loopback, HAProxy завершает TLS и перенаправляет HTTP и WebSocket с префикса `/mmo/`, удаляя его перед отправкой в Colyseus.
